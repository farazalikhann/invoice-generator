Privacy Policy

Last updated August 9, 2026

The short version

Everything you type into the invoice tool — your business details, client details, line items, and any logo you upload — stays on your device. It is never transmitted to us or to any third party. There is no server behind this tool that receives or stores your invoice data.

What is stored, and where

The tool uses your browser's local storage to remember three things between visits, so you don't have to retype them:

  • Your "From" business details and preferred currency
  • Your uploaded logo (saved as an image encoded directly in local storage)
  • Your chosen template and accent color, and a history of invoices you've downloaded (capped at 25)

Local storage is a browser feature, not a database we operate — this data lives only in the browser you're using, on the device you're using it on. Clearing your browser data, using a different browser, or using a different device means it won't be there. You can also clear it yourself at any time with the "Clear Saved Data" and "Clear All History" buttons in the tool.

What we don't do

  • We don't require an account, email address, or any personal information to use the tool.
  • We don't use tracking or advertising cookies.
  • We don't run analytics scripts that profile individual visitors.
  • We don't upload, transmit, or store the invoices, client details, or logos you create with this tool.

Third-party resources

This site loads one third-party script: the open-source jsPDF library, served from the Cloudflare CDN (cdnjs.cloudflare.com), which is what generates your downloadable PDF. Loading that file means your browser makes a request to Cloudflare's servers, which — like any web request — may log standard technical information such as your IP address, in line with Cloudflare's own privacy practices. No invoice content is included in that request; it's only fetching the library code itself.

If this site is hosted on a static hosting provider (as most static sites are), that provider's servers will log basic technical access information (such as IP address and requested page) as part of normal web hosting operation. That's standard server behavior, separate from anything the invoicing tool itself does.

Children's privacy

This tool is intended for general business use and is not directed at children. It does not knowingly collect information from anyone, of any age, since it does not collect information at all.

Changes to this policy

If this policy changes, the "last updated" date at the top of this page will change too. Since this is a static tool with no accounts, we have no way to notify you individually — check back here if you want to review the current version.

Contact

Questions about this policy can be sent via the Contact page.
